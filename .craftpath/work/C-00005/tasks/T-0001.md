# T-0001 — Task subagents report their decisions instead of writing them

- **Work:** C-00005
- **Type:** feat
- **Wave:** 1
- **Depends on:** none
- **Touches:** assets/steps/work.md, test/steps/work.test.ts
- **Scenarios:** S1, S2, S7

## Acceptance criteria

- **A1** Given a fresh project, when `init --harness claude-code,pi` runs, then in the installed `craftpath-work` skill on both harnesses, the brief (the text after `## The brief for each task's subagent`) has a paragraph that tells the subagent to end its reply with the decisions it made on its own, each with its reason, or `` `none` `` when it made none: that paragraph contains `decisions`, `reason` and `` `none` ``, and comes before the brief's last paragraph, which still contains `` `DONE` `` and `` `STUCK: `` (the final status line) — proven by integration test `work's brief asks each subagent to report its decisions before DONE or STUCK`
- **A2** Given a fresh project, when `init --harness claude-code,pi` runs, then no paragraph of the installed `craftpath-work` brief, on either harness, contains both `decisions` and `Notes`, and a paragraph still tells the subagent to write under Notes what else the reviewer should know (it contains `Notes` and `reviewer`) — proven by integration test `work's brief keeps decisions out of the task file's Notes`
- **A3** Given a fresh project, when `init --harness claude-code,pi` runs, then a paragraph of the installed `craftpath-work` brief, on both harnesses, tells the subagent not to create or edit `DECISIONS.md`: it contains `` `DECISIONS.md` `` and the phrase `not create or edit` — proven by integration test `work's brief forbids the subagent DECISIONS.md`
- **A4** Given the sources in `assets/steps/`, when each file is searched for `DECISIONS.md`, then `work.md` is the only one that contains it — proven by integration test `work is the only step that names DECISIONS.md`
