# T-0004 — Teach verify to categorise findings

- **Work:** C-00016
- **Type:** feat
- **Wave:** 4
- **Depends on:** T-0003
- **Touches:** assets/steps/verify.md, assets/steps/verify-fix.md (wording only if needed)
- **Scenarios:** S1, S2, S3, S4, S11

## Acceptance criteria

- **A1** Given the verify step installed for Claude Code and for pi, when its text is read, then both tell the agent to write each confirmed finding as `- [ ] F<n> [fix|you|noted] <file:line> -- given ..., ...` and none still shows `[major|minor]` — proven by integration test `the verify step writes the three categories on both harnesses`
- **A2** Given the installed verify step, when its text is read, then it says a confirmed finding is `[fix]` by default and names a confirmed missing test for a `SPEC.md` scenario as the example — proven by integration test `verify defaults confirmed findings to fix`
- **A3** Given the installed verify step, when its text is read, then it says `[you]` is for a finding whose fix would change scope, intent or user-visible behaviour the spec leaves unsettled, and that no task is made from it — proven by integration test `verify tags unsettled behaviour as you`
- **A4** Given the installed verify step, when its text is read, then it says `[noted]` is for a real finding not worth changing code for, and that no task is made from it — proven by integration test `verify tags not-worth-fixing findings as noted`
- **A5** Given the installed finder's brief, when its text is read, then it no longer asks for `major|minor` and the severity guidance is gone, so the refuter still sees only the findings — proven by integration test `the finder brief carries no severity tag`

## Notes

This task is wording in an agent step, so its criteria are proven on the
installed text, the way C-00015's step tests do it (`test/steps/verify.test.ts`).
That proves the instruction is installed, not that the model follows it;
following it is what `check.py verify` (T-0001) enforces for the tag, and the
judgement between the three is left to the agent (decided: a script cannot
tell a bug from an unsettled behaviour). The finder keeps proposing findings
without a category; the categorising is the verify step's own, after the
refuter confirms, so the refuter's brief stays free of anything but findings.
